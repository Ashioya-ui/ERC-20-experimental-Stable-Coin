# Paper fixtures

Data from the numerical section of E. Langetepe and W. A. Ashioya, "The length-over-diameter
ratio of self-approaching curves" (revised version 21, October 2026), used by the Phase 4
tests in `test/paper/` (see PROMPTS.md, Phase 4, Track C).

| File | What it shows |
|---|---|
| `self_contracted_cap_31.json` | Section 7.5: a 31-point sequence in the cap K that satisfies the self-approaching triple condition at its own points (up to a relative error of 2e-12), yet its polygon violates Lemma 7.1 at 68 index pairs and has length 2.0907, more than per(K) = 1 + pi/3 = 2.0472. A check made only at sampled points would accept it. On-chain checks must test the polygon (Lemma 7.1). |

| `differential_1000.json` | 1,000 integer polygons with what the paper's own code (`sa_fix/code/sapoly.py`: `pair_index`, `sa_residuals`, `length`) says about each: the Lemma 7.1 verdict, the largest squared distance from the start, and the rounded length. Generated by `gen_differential.py` (seed 20261016); coordinates stay below 2^20 so the paper's float64 arithmetic is exact. Checked by `test/paper/Differential.t.sol`. |

In `self_contracted_cap_31.json`, coordinates are decimal strings of integers equal to
value * 1e18 (`xs`, `ys`); read them with `vm.parseJsonStringArray` and `vm.parseInt`. In
`differential_1000.json` they are plain integers, concatenated, with `offsets[p]` the first
vertex of polygon `p`.
